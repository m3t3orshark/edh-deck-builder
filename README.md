# edh-deck-builder

*[English version](README.en.md)*

Un **skill pour Claude** qui construit, analyse et améliore des decks **Magic: The Gathering Commander (EDH)** de 100 cartes, en papier : listes vérifiées (légalité, bracket, combos, prix) et prêtes à importer dans deckstats.net, ManaBox, Moxfield ou Archidekt, puis notes de jeu.

## Installer

Dix minutes, une seule fois : régler Claude (exécution de code, accès réseau, cinq domaines), télécharger `edh-deck-builder.skill` depuis la page **[Releases](https://github.com/m3t3orshark/edh-deck-builder/releases)**, l'importer dans Claude, puis régler tes préférences au premier message.

**[Le guide d'installation pas à pas](INSTALLATION.md)**

## Utiliser

Dis **« aide EDH »** à tout moment pour voir ce que le skill sait faire. Le [mode d'emploi](edh-deck-builder/docs/MODE_EMPLOI.md) détaille tout.

## Mettre à jour

Dis **« fais la mise à jour EDH »** : Claude vérifie ici s'il existe une nouvelle version, te résume les nouveautés, vérifie le fichier, garde tes réglages et te présente la mise à jour à installer d'un clic. Les nouveautés de chaque version sont dans [CHANGELOG.md](CHANGELOG.md).

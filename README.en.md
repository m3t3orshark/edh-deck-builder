# edh-deck-builder

*[Version française](README.md)*

A **skill for Claude** that builds, reviews and improves **Magic: The Gathering Commander (EDH)** decks of 100 cards, for paper play: checked lists (legality, bracket, combos, prices) ready to import into deckstats.net, ManaBox, Moxfield or Archidekt, then play notes.

## Install

Ten minutes, once: set up Claude (code execution, network access, five domains), download `edh-deck-builder.skill` from the **[Releases](https://github.com/m3t3orshark/edh-deck-builder/releases)** page, import it into Claude, then set your preferences in your first message.

**[The step-by-step installation guide](INSTALLATION.en.md)**

## Use

Say **"help EDH"** at any time to see what the skill can do. The [user guide](edh-deck-builder/docs/MODE_EMPLOI.en.md) covers everything.

## Update

Say **"update EDH"**: Claude checks here for a new version, summarizes what's new, checks the file, keeps your settings and gives you the update to install in one click. What's new in each version is in [CHANGELOG.md](CHANGELOG.md).
